# Security policy

Please do not open public issues for suspected vulnerabilities. Report them privately to the repository owner with reproduction steps, affected versions, and potential impact.

This repository contains deterministic local demo identities only. Never reuse the demo password or default JWT secret outside an isolated development environment. Production deployments should use managed identity, secret rotation, private ML endpoints, least-privilege IAM, and a dedicated AWS account.

Supported security fixes target the current default branch.
